# Address Autofill - Visual User Guide

## 🎯 What's New

You no longer need to type your business address every time you create a shift! The app now remembers your business address and fills it automatically.

---

## 📱 How It Works

### **Step 1: Set Your Business Address (One Time)**

When you first complete your profile or edit it later:

```
┌─────────────────────────────────────┐
│  Complete Your Profile              │
├─────────────────────────────────────┤
│                                     │
│  Business Address *                 │
│  ┌───────────────────────────────┐ │
│  │ 45 Queen Victoria Street, L...│ │
│  └───────────────────────────────┘ │
│                                     │
│  💡 Quick Fill:                     │
│  [London] [Manchester] [Birmingham] │
│                                     │
│  Suggestions:                       │
│  → 45 Queen Victoria Street, London │
│  → Manchester M1 1AD, UK            │
│  → Birmingham B1 1AA, UK            │
│                                     │
│  ℹ️ This will be used as default    │
│     shift location                  │
│                                     │
│       [Continue to Dashboard]       │
└─────────────────────────────────────┘
```

**What happens:**
- Type or select your address
- Gets saved to your business profile
- Used for all future shifts

---

### **Step 2: Create a Shift (Auto-Filled!)**

When you create a new shift:

```
┌─────────────────────────────────────┐
│  Create Shift                       │
├─────────────────────────────────────┤
│                                     │
│  Shift Title *                      │
│  [Server                         ]  │
│                                     │
│  Location *                         │
│  ┌───────────────────────────────┐ │
│  │ 45 Queen Victoria Street,     │ │
│  │ London EC4N 4SA, UK           │ │
│  │                               │ │
│  │ 📍 Your business address      │ │
│  └───────────────────────────────┘ │
│                                     │
│  Use different location for this    │
│  shift                              │
│                                     │
│  Date *                             │
│  [2026-03-15                     ]  │
│                                     │
│       [Create Shift]                │
└─────────────────────────────────────┘
```

**What happens:**
- Location is already filled
- Blue border shows it's from your profile
- Just fill other fields and create!

---

```
┌─────────────────────────────────────┐

│  └───────────────────────────────┘ │
│                                     │
│  💡 Quick Fill:                     │
│  [London] [Manchester] [Birmingham] │
│                                     │
│  ← Use business address instead     │
│                                     │
```

**What happens:**
- Click "Use different location"
- Address autocomplete appears
- Type custom location
- Click "Use business address instead" to revert

## 🎨 Visual Indicators

| State | Appearance | Meaning |
|-------|-----------|---------|
| **Auto-filled** | Blue border box with 📍 icon | Using your business address |
| **Loading** | Spinner + "Loading..." | Fetching your address |
| **Custom** | White input box | Custom location for this shift |
| **Quick Fill** | Blue pill buttons | One-tap city selection |
| **Suggestions** | Dropdown list | Matching locations |

---

## 💡 Pro Tips

1. **Set accurate address during profile setup** - Saves time later
2. **Use quick fill buttons** - Faster than typing
3. **Override only when needed** - Keep most shifts consistent
4. **Update via ProfileHub** - Changes apply to future shifts only

---

## 🐛 Troubleshooting

### "Loading business address..." stuck?
- Check internet connection
- Refresh the app
- Make sure profile is complete

### Location not auto-filling?
- Ensure you set business address in profile
- Go to ProfileHub → Location to add it
- Restart the app if needed

### Want to change all past shifts?
- Business address only applies to new shifts
- Edit old shifts individually if needed

## 📊 Example Workflow

```
Day 1: Complete Profile
└─> Enter: "123 Main Street, London, UK"
    
Day 2: Create Shift #1
└─> Location: Auto-filled ✅
    
Day 3: Create Shift #2  
└─> Location: Auto-filled ✅

└─> Click "Use different location"

```

Each shift after the special event returns to your business address automatically!
